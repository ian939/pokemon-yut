# 포켓몬 윷놀이 🎲

잉글리시몬 도감에서 모은 포켓몬이 **윷판 위의 말**이 되는 가족 윷놀이예요. 패드 한 대를 돌려 가며 가족끼리 하거나, 혼자서 로켓단과 대결해요.

**▶ 플레이: https://ian939.github.io/pokemon-yut/**

## 게임 방법

1. **👨‍👩‍👧 가족 대결** 또는 **😈 로켓단 대결**을 골라요 (말 2·3·4개, 빽도 켜기/끄기)
2. 팀마다 포켓몬을 골라요 — 잉글리시몬 도감에서 잡은 포켓몬 중에서, 모자라면 빌려온 친구로
3. **🎲 윷 던지기!** → 결과마다 같은 동물 포켓몬이 알려 줘요

   | 도 | 개 | 걸 | 윷 | 모 | 빽도 |
   | --- | --- | --- | --- | --- | --- |
   | 🐷 뚜꾸리 1칸 | 🐶 가디 2칸 | 🐑 메리프 3칸 | 🐮 켄타로스 4칸 + 한 번 더 | 🐴 포니타 5칸 + 한 번 더 | 야돈 뒤로 1칸 |

4. 움직일 말을 누르면 도착할 칸이 반짝여요 → 그 칸을 누르면 한 칸씩 콩콩 이동
5. 내 포켓몬이 먼저 전부 참먹이로 **골인**하면 승리! 🏆

## 윷놀이 규칙 (진짜 윷놀이 그대로)

- **윷·모**가 나오면 한 번 더 던져요. 쌓인 결과는 원하는 순서로 써요
- **위쪽 두 모서리**나 가운데 **방**에 딱 멈추면 지름길(대각선)로 가요
- 내 말끼리 같은 칸에 서면 **업어서** 같이 가요 (×2)
- 상대 말이 있는 칸에 멈추면 **배틀**(잡기) — 물리친 상대 포켓몬은 집(출발 자리)으로 돌아가고, 이긴 팀은 한 번 더!
- 아이가 좌절하지 않게 **낙은 없어요**. 참먹이에 도착하거나 지나가면 골인

## 포켓몬 윷놀이만의 재미

- **✨ 진화** — 말은 진화 1단계 모습으로 출발해서, 판을 돌며 고른 포켓몬 모습까지 진화해요 (리자몽을 고르면 파이리 → 리자드 → 리자몽). 잡히면 처음 모습으로 돌아가요. 한 진화 가족에서는 한 마리씩만 골라요
- **⚔️ 배틀** — 상대 말이 있는 칸에 멈추면 포켓몬 배틀 화면! "리자몽의 화염방사!"로 물리치면 상대 포켓몬은 집(출발 자리)으로 돌아가요
- **😈 로켓단** — 🌱 쉬움 / 🔥 보통. "귀염둥이 악당, 포켓몬의 감초~!"
- 한국어로 결과·차례를 읽어 주고, 포켓몬 울음소리가 나요
- 판은 자동 저장 — 나갔다 와도 **이어하기**. 사람별 전적

## 잉글리시몬과의 연결

- 같은 주소(`ian939.github.io`)라서 잉글리시몬 도감을 **읽기만** 해요. 코인·볼과는 관계없어요
- 패드가 저장을 따로 쓰면 고르기 화면의 **🔗 가족 코드로 도감 불러오기** (잉글리시몬 가족 함께하기 코드, 읽기만)

## 폴더

| 경로 | 내용 |
| --- | --- |
| `index.html` | 게임 화면·연출·저장 |
| `yut-rules.js` | 규칙 엔진 (DOM 없음, Node 테스트) |
| `lock.js` | 패드 확대·복사 잠금 |
| `data/pokemon.js` | 포켓몬 이름·타입·희귀도·지역·진화 순서 — `tools/`로 생성 |
| `assets/` | 포켓몬 도트 앞·뒷모습·일러스트(PokeAPI) + 윷판·윷가락·멍석·배경·배틀 무대(직접 그림) |
| `tools/` | 데이터·그림 만들기, 테스트 |
| `docs/` | [기획서](docs/기획서.md) · [기술 스펙](docs/기술스펙.md) |

```bash
node tools/test-rules.js          # 규칙 테스트 22개
node tools/sim-cpu.js             # 로켓단 난이도 시뮬레이션
python tools/test-ui.py           # 화면 검사 (Playwright)
```

`index.html`을 그냥 열어도(`file://`) 돌아가요. 개발용 주소 옵션: `?fast=1`(연출 빠르게) · `?seed=12` · `?force=5,4,3`(다음 윷 결과 정하기).
