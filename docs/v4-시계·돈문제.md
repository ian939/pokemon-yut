## 1. 한눈에

```
🌿 ❓ 풀숲에 멈춤 ─▶ 🕐 시계 문제 (보기 4개) ─ 맞힘 ─▶ 이번 조우: 일반 30 · 레어 30 · 유니크 20 · 전설 20
                                           └ 틀림 ─▶ 정답 풀이 보여 주고, 원래 확률 50 · 30 · 10 · 10
😈 로켓단 이김 ─▶ 🎁 상자 (볼 3개, 지금 그대로) ─▶ 💰 돈 문제 ─ 맞힘 ─▶ 볼 1개 더
```

- 목적은 **교육**: 초1 지온이가 시계(몇 시·몇 분)와 돈(자릿값: 백·천·만·십만)을 **놀이 안에서 여러 번** 보게 한다
- 문제는 짧게(한 문제, 10초 안팎), 틀려도 **왜 그런지 보여 주고** 넘어간다 — 놀이가 끊기지 않게

## 3. 🕐 시계 문제

### 3-1. 시계 그림 — 코드로 그린다 (SVG)
- 사진처럼: 흰 테두리 원 · 1~12 큰 숫자(빨·주·초·파 돌아가며) · 바깥 작은 **분 숫자 0·5·10…55** · 1분 눈금 60개
- 게임 톤: 먹선 테두리(DS 창과 같은 `--ink`) · 도트 글꼴 숫자
- 바늘: **시침 = 짧고 굵은 빨강**, **분침 = 길고 가는 파랑** (사진은 둘 다 빨강이라 아이가 헷갈림 → 색으로 나눈다), 초침은 없음
- 시침은 진짜 시계처럼 **분만큼 사이로 움직인다** (3시 30분이면 3과 4 사이) — 이게 시계 보기의 핵심 함정
- 이미지 생성(Codex)이 아니라 코드로 그리는 이유: 바늘을 문제마다 정확한 각도로 돌려야 해서

### 3-2. 흐름 (풀숲에 멈추면)
1. "풀숲이 흔들린다! 🕐 시계를 맞히면 **희귀한 포켓몬**이 나올지도?"
2. 시계 + "지금 몇 시 몇 분일까요?" + 보기 4개 (44px 이상 큰 버튼, 읽어 주기)
3. 맞힘 → ⭐ "정답! 전설이 나올 확률이 올라갔어요!" → 확률 30·30·20·20으로 포켓몬을 **그때 뽑는다**
4. 틀림 → 정답 칸이 빛나고 **풀이**: 짧은 바늘이 가리키는 곳 → "몇 시", 긴 바늘 숫자 × 5 → "몇 분"을 바늘을 반짝이며 보여 줌 → 원래 확률로
5. 그다음은 지금과 같은 조우(볼 던지기 → 말 바꾸기)
- 로켓단이 풀숲에 멈추면 문제 없음 (그물 그대로, 원래 확률)
- 지금은 풀숲 포켓몬을 판 만들 때 미리 뽑아 두는데 → **문제를 푼 뒤에 뽑도록** 바꾼다 (뽑은 즉시 저장 — 새로고침으로 다시 뽑기 불가)

### 3-3. 보기 4개 만드는 법 — 아이가 실제로 하는 실수로
| 오답 | 예 (정답 3:40) | 왜 |
| --- | --- | --- |
| 시침을 다음 숫자로 읽음 | 4:40 | 3과 4 사이에 있으니 4라고 읽는 실수 |
| 시·분 바늘을 바꿔 읽음 | 8:15 | 긴 바늘=시로 읽는 실수 |
| 분을 숫자 그대로 읽음 | 3:08 | 분침이 8을 가리켜서 "8분" |
- 보기가 겹치면 ±5분·±1시간으로 채운다. 정답 위치는 무작위

### 3-4. 어려움 ✅ U8
| 단계 | 시각 | 학교 |
| --- | --- | --- |
| 1 | 몇 시 정각 · 몇 시 30분 | 1학년 2학기 |
| 2 | 5분 단위 (3:25) | 2학년 |
| 3 | 1분 단위 (3:27) | 2학년 |
- **자동으로 오르내림** — 같은 단계를 3번 연속 맞히면 다음 단계, 2번 연속 틀리면 한 단계 내림. 단계는 저장(가족 공용)

## 4. 💰 돈 문제 (보물상자 볼 1개 더)

### 4-1. 흐름
1. 상자에서 볼 3개가 나온 뒤 "🎁 상자 바닥에 뭔가 더 있다! 돈 문제를 풀면 볼 하나 더!"
2. 돈 그림을 보여 주고 "모두 얼마일까요?" 보기 4개
3. 맞힘 → 볼 1개 더 (확률은 상자와 같게 50·30·10·5·5) → 가방에 넣고 저장
4. 틀림 → 단위별로 묶어 세는 풀이 ("만 원 3장 = 30000원, 천 원 2장 = 2000원 … 모두 32500원") → **새 문제로 한 번 더** → 맞히면 몬스터볼 1개, 또 틀리면 풀이만 보고 끝

### 4-2. 돈 그림 — 코드로 그린 "놀이 돈"
- 진짜 지폐 그림을 베끼지 않는다 (위조처럼 보이지 않게). 단위마다 색과 크기가 다른 간단한 지폐·동전 + 큰 숫자
  - 🟪 **100000** (수표 모양, 보라) · 🟩 **10000** (초록 지폐) · 🟦 **1000** (파랑 지폐) · ⚪ **100** (은색 동전)
- 같은 단위끼리 모아 놓는다 (아이가 묶어 세기 쉽게)

### 4-3. 문제 모양 — A로 확정 ✅ U9 (B·C는 나중에)
| 모양 | 예 | 기르는 힘 |
| --- | --- | --- |
| A. 모두 얼마? | 만 원 3장 + 천 원 2장 + 백 원 5개 → ① 32,500원 ② 3,250원 ③ 325,000원 ④ 35,200원 | 자릿값, 묶어 세기 |
| B. 알맞게 내기 | "24,300원을 내려면?" → 돈 묶음 4개 중 고르기 | 수 → 돈 |
| C. 섞어서 | A·B 무작위 | |
- 오답은 **자릿값 실수**로 만든다: 한 자리 밀림(3,250 / 325,000) · 단위 바꿔 읽음(35,200) · 한 장 덜/더 셈
- 숫자는 **쉼표 + 한글 읽기** 같이: "32,500원 (삼만 이천오백 원)"

### 4-4. 어려움
| 단계 | 쓰는 돈 | 합 |
| --- | --- | --- |
| 1 | 천 원 · 백 원 | 9,900원까지 |
| 2 | 만 원 · 천 원 · 백 원 | 99,900원까지 |
| 3 | 십만 원 · 만 원 · 천 원 · 백 원 | 999,900원까지 |
- 시계와 같은 자동 오르내림 (❓ Q2와 같이 정한다). 한 단위는 최대 9장(자릿값 그대로)

## 5. ✨ 기술 쓰는 때 바꾸기 ✅ U10

지금: 3단계 포켓몬은 10칸(마지막 모습)에 기술, **2단계는 5칸**, **진화 없음은 처음부터**, 전설은 처음부터 → 불공평
바꿈: **진화 없음·2단계·전설**은 **15칸** 가야 기술을 배운다. 3단계는 지금처럼 마지막 모습(10칸)에서 — 칩 아래 점으로 "기술까지 남은 칸"을 보여 준다
- 말 바꾸기로 들어온 포켓몬도 같은 규칙 (간 칸 수 이어받기 그대로)

## 6. 화면·저장

- 새 창 두 개: **시계 문제 창**, **돈 문제 창** (DS 대화창 모양, 버튼 44px+, 읽어 주기, 풀이 애니메이션)
- 판 설정(준비 화면)에 **🎓 공부 문제 켜기/끄기** ❓ (제안: 켜기가 기본. 끄면 지금처럼)
- 저장: `study: { clock: { level, streak, right, total }, money: { … } }` — 🏆 전적 창에 "시계 12/15 · 돈 8/10" 표시(부모님이 보기)
- 테스트용 주소: `?clock=3:40`(시계 시각 정하기) · `?money=0,3,2,5`(십만·만·천·백 장 수 정하기)
